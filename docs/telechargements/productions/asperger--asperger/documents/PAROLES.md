# Ici — Paroles

**Tonalité :** Fa# mineur (F#m)
**Tempo :** 72 BPM
**Guide Voix :** à définir (en attente d'une piste d'enregistrement)
**Tessiture :** baryton, phrases courtes, graves, respirées (rien d'aigu)

**Structure :** Intro (8) → Couplet 1 (16) → Refrain 1 (8) → Couplet 2 (16) → Refrain 2 (8) → Pont (8) → Refrain final x2 (16) → Outro (8)

---

## Légende des annotations

- `E3 ◷3` = note tenue 3 temps — attaquer la syllabe suivante sur cette note
- `→` = enchaînement sans nouvelle attaque
- `...` = silence / respiration
- Les notes guides sont des **brouillons** — à caler précisément à l'enregistrement

## Contraintes narratives (verrouillées avec David)

- **Pas de dialogue.** Le refrain est pensé / observé, jamais adressé.
- **Pas de vocabulaire psy.** Jamais « comprendre », « accepter », « différent ». On montre, on ne nomme pas.
- **Le capitaine n'explique rien.** Pas de « je te reconnais », pas de « moi aussi ». Juste des faits, des gestes, des climats.
- **Le gamin reçoit.** Le refrain peut basculer de son point de vue — ce qu'il ressent sans le dire.
- **Ton témoin.** On raconte, on ne prêche pas.
- **Baryton.** Phrases courtes, graves, respirées. Rien d'aigu, rien de virtuose.

## Notes d'adaptation

- Les couplets sont des **brouillons écrits à partir des directions A/B/C validées** (planter le décor ; gestes du capitaine ; objets laissés sur le chemin). À ajuster ensemble lors de l'atelier paroles.
- Le refrain est **verrouillé tel quel** (Proposition 2 validée).
- Le pont reprend la direction C (faits presque froids) pour contraste.
