## Notes de production

- **Convention MIDI** : Ableton affiche **C3 = 60**. Le document source (`Discussion_C'est_Evident.md`) annonce « C4 = 60 » et nomme donc ses notes une octave au-dessus de l'affichage Ableton. **Se fier aux numéros MIDI**, pas aux noms. Ex. le guide couplet descend à MIDI 50-54 (affiché D2-F#2).
- **Choix native-first** : la source proposait Surge XT pour basse/pad/pluck/lead. Template final = **instruments natifs Live** (Drift + kits `.adg`), pour rester léger (CPU ≈ 2.5 % au repos) et ne pas dépendre de plugins externes. Une instance Surge XT peut être ajoutée en couche si un timbre manque.
- **Abandon du Resampling** : le plan source réservait la piste 8 au Resampling. Remplacé par la convention de `sources/Calme` : **7 = Guide-Voix (MIDI)**, **8 = Voix (audio)**. Budget : 8 pistes exactement.
- **Guide vocal — deux versions testées**, David retient **la version grave** (celle écrite). La version +1 octave (test) a été supprimée.
- **Pré-refrain** : la source se contredit — le plan d'arrangement dit « coupe la batterie », la spec détaillée dit « batterie continue sans le kick du temps 1 ». Retenu : **kick retiré du temps 1**, snare + charleys conservées. Puis **David a baissé la vélocité de la snare à la limite de l'audible** (choix artistique).
- **Pluck pré-refrain** monte haut (jusqu'à MIDI 85) : c'est le rôle de tension avant le refrain.
