## Notes d'interprétation

- **Couplet** : reste dans le grave (MIDI 50-66), parlé-chanté nonchalant — c'est la signature.
- **Pré-refrain** : monte (E3→G3→A3), ajoute du souffle, la fin de phrase tient sur A2.
- **Refrain** : ouvre les voyelles sur « é-vi-**dan** », « douce-**man** », « simple-**man** ».
- **Pont** : redescends, chuchote presque, puis relance le refrain final.
- **Adlibs** : « bébé », « oh », « yeah » dans les silences du refrain final.
- **Retenue validée** : David a écouté les deux guides (grave / +1 octave) et préfère **la version grave**.
