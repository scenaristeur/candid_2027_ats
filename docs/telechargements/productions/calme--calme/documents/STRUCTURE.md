# Calme — Structure & Production

**Tonalité :** G majeur
**Tempo :** 92 BPM
**Durée :** ~1m55 (44 mesures)

## Arrangement détaillé

| Section | Mesures | Pistes actives | Description |
|---|---|---|---|
| **Intro** | 1-4 | 1+4+6 | Drums soft + nappe Gmaj7→Em7 + percs légères |
| **Couplet 1** | 5-12 | 1+2+3+4+6 | Entrée basse + guitare, calme posé |
| **Refrain** | 13-20 | 1+2+3+4+5+6 | Lead + énergie douce, le temps s'arrête |
| **Couplet 2** | 21-28 | 1+2+3+4+6 | Même base, plus aérien |
| **Refrain** | 29-36 | 1+2+3+4+5+6 | Identique, plus ouvert |
| **Pont** | 37-40 | 1+2+4 | Allégé, émotion, puis buildup |
| **Outro** | 41-44 | 1+4 | Fade, nappe Gmaj7 + « oh doucement » → silence |

## Notes de production

### Rythmique
- **Basse :** groove cool et posé, notes tenues
- **Drums :** kick discret, pattern aéré, pas de four-on-the-floor
- **Sidechain :** compression légère kick/basse pour le pump doux
