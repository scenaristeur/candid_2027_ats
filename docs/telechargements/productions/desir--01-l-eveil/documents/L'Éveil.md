# 01 — L'Éveil (Introduction instrumentale)

**Tempo**: 70 BPM
**Durée**: 2:15
**Atmosphère**: Douce, contemplative

## Structure
A-B-A'
- **A (0:00-0:45)**: Am - C (2 mesures chaque)
- **B (0:45-1:30)**: G - F - Am - C
- **A' (1:30-2:15)**: Am - C avec nappes ajoutées

## Mélodie Piano
- Main droite: Notes ascendantes en triolets (E-G-C / F-A-D)
- Main gauche: Arpèges lents (Am: A-E-A-C)
- Progression mélodique: Simple, répétitive, méditative

## Ableton Setup
- Piste 1: Piano (Grand Piano) + Reverb (50% wet)
- Piste 2: Pad Analog (preset "Warm Pad") très discret

## Production Notes
- Utiliser l'effet "Reverb" sur le piano avec un "Decay Time" long
- Pas de paroles — instrumental uniquement
