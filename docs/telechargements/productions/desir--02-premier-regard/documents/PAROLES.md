# 02 — Premier Regard — Paroles

**Tonalité :** Sol majeur (G)
**Tempo :** 85 BPM
**Guide Voix :** Sweet Lead (piste 3)
**Tessiture guide :** E3–C4 (confortable baryton/ténor)

**Structure :** Intro (4) → Couplet 1 (8) → Pré-refrain (8) → Refrain (8) → Couplet 2 (8) → Pré-refrain (8) → Refrain (8) → Pont (8) → Refrain final (8) → Outro (4)

---

## Légende des annotations

- `G3 ◷3` = note G3 tenue 3 temps — attaquer la syllabe suivante sur cette note
- `→` = enchaînement sans nouvelle attaque
- `...` = silence / respiration

## Notes d'adaptation

- **Couplet** : phrasé parlé-chanté, ne pas forcément caler chaque syllabe — la note guide marque le temps fort, le flow vient naturellement
- **Refrain** : le saut d'octave sur "regard" (C4→G3 ou D4→A3) donne l'emphase — bien le marquer
- **Pont** : notes tenues longues (8 temps), voix plus fragile, presque chuchotée
- **Guide voix (Sweet Lead)** : son clair mais doux — baisser le volume pour qu'il se fonde sans dominer
