## 1. Analyse rapide des paroles

**Thèmes**
- **La myopie volontaire** : ne pas voir l’écume, les modes, le marketing, le bullshit ; voir les lames de fond, les mécanismes, la profondeur.
- **La Noosphère** : espace mental, immatériel, sphère des idées et des représentations.
- **Le Château des Robots** : port d’attache, base arrière, lieu de départ.
- **El Fada** : capitaine, guide, figure de lucidité.
- **Les Myopes** : équipage, collectif, chercheurs de sens.
- **Découverte de soi et des autres** : chaque couplet est une plongée intime ; le refrain est un rituel collectif ; le pont est une prise de conscience ; l’outro est une promesse intérieure.

**Structure**
- Intro parlée
- Couplet 1
- Refrain
- Couplet 2
- Refrain
- Pont
- Couplet 3
- Refrain final
- Outro

**Prosodie / chant**
- Certains vers sont longs : il faut les **couper en cellules rythmiques**.
- Le refrain est parfait pour du **call-and-response**.
- Les voyelles nasales (`an`, `in`, `on`) et les `ô` sont des appuis naturels pour un baryton.
- Les consonnes `t`, `k`, `p`, `b` doivent être **percussives**, comme des coups de rame.

**Ajustements à la marge**
- Découper les vers longs.
- Ajouter des réponses d’équipage.
- Ajouter des respirations.
- Renforcer les répétitions percussives.
- Garder le sens, la couleur, les mots-clés.

## 2. Guide vocal baryton

**Tonalité conseillée** : Ré mineur (Dm)  
**Tessiture** : D3–F4  
Si c’est inconfortable, transposez en **Do mineur (Cm)** ou **Si mineur (Bm)**.

**Tempo** : 96 BPM, mesure 4/4  
**Feu rythmique** : chant marin lourd, presque hypnotique.  
**Percussions** :  
- Pied sur temps 1 et 3  
- Clap sur temps 2 et 4  
- Refrain : double frappe sur « Hisse, hisse »

**Respiration**
- Couplets : souffle après chaque vers, ou toutes les deux cellules.
- Refrain : souffle après « El Fada », « débats », « pas », « tra-la-la », « fond », « changements », « sous-jacents », « gens », « enfin ».
- Pont : respiration ample, débit parlé-rythmé.

**Articulation**
- Attaques nettes : `Du Châ-teau`, `s’é-lan-ce`, `hou-blots`.
- Allonger les voyelles : `si-lence`, `bru-me`, `fond`, `gens`.
- Ne pas forcer les aigus : rester dans le masque, poitrine ouverte, vibration légère.

**Mélodie indicative**
- Couplets : récitatif sur **D3–F3–G3–A3**.
- Refrain : « Hisse, hisse » sur **A3–A3**, puis « capitaine El Fada » sur **D4–C4–A3–G3–F3–E3–D3**.
- « Cap sur la Noosphère » monte à **F4**.
- Pont : parlé sur **D3**, puis montée à **A3** sur « Nous, on cherche ».
- Outro : redescente douce sur **D3**, chuchotée.

**Dynamique**
- Intro : *p*
- Couplets : *mf*
- Refrain : *f*
- Pont : *mp* → crescendo → *f*
- Refrain final : *ff*, ralenti sur les deux derniers vers.
- Outro : *p*, presque murmuré.

- **Couplets** : joue l’introspection, la confidence. Tu es El Fada qui parle à voix basse à son équipage.

- **Pont** : ralentis légèrement, presque parlé. C’est le moment de lucidité.
- **Outro** : termine en suspension. La découverte continue après la chanson.

Ainsi, « Les Myopes » devient un chant de mer intérieur : on navigue vers les autres pour se découvrir soi-même.

## CONSEIL DE MIXAGE

- **Basse** : bien ronde, présente, jamais masquée.  
- **Grosse caisse** : cœur du morceau, presque viscérale.  
- **Voix lead** : au centre, légèrement compressée, avec réverbération courte (cabine de navire).  
- **Chœurs** : large stéréo, un peu en arrière, avec réverbération plus longue (Noosphère).  
- **Accordéon / harmonium** : en nappe, pas trop forts, pour la couleur.  
- **Banjo / mandoline** : à gauche ou à droite, pour la brillance percussive.

Ainsi, chaque partie a sa couleur, chaque répétition sa variation, et le morceau raconte une **plongée progressive** : du quai des signaux jusqu’aux abysses de la Noosphère intérieure.

## 1. PISTE BASSE (Surge XT)

### Preset de départ
Chercher dans les factory presets : **Basses → “Sub Bass”** ou **“Reese Bass”** (pour la texture).  
Alternative : charger un preset de basse sinusoïdale pure et le modeler.

### Réglages Surge XT
| Paramètre | Valeur |
|---|---|
| Osc 1 | Sinus (Sub) — octave -1 |
| Osc 2 | Saw — octave 0, légèrement désaccordé (-5 cents) |
| Osc 3 | Off |
| Filtre | Lowpass 24 dB, cutoff 180 Hz, résonance 0.1 |
| Enveloppe Amp | A: 0 ms, D: 200 ms, S: 1.0, R: 400 ms |
| Enveloppe Filter | A: 5 ms, D: 300 ms, S: 0.4, R: 300 ms |
| Modulation | LFO 1 → cutoff (profondeur 0.15, rate 0.5 Hz) |

### Grille d’accords (mesures 9–24)

```
Dm        Bb        F         C
Dm        Bb        Gm        A
```

**Ligne de basse (mode marin, noires et croches) :**

```
Mesure 1 (Dm) : D2 — D2 — F2 — D2
Mesure 2 (Bb) : Bb1 — Bb1 — D2 — Bb1
Mesure 3 (F)  : F2 — F2 — A2 — F2
Mesure 4 (C)  : C2 — C2 — E2 — C2
Mesure 5 (Dm) : D2 — D2 — F2 — A2
Mesure 6 (Bb) : Bb1 — D2 — F2 — D2
Mesure 7 (Gm) : G2 — G2 — Bb2 — G2
Mesure 8 (A)  : A2 — A2 — C#3 — E3
```

### Automation (Arrangement View)
- **Cutoff du filtre** : clic droit sur le paramètre Cutoff → “Show Automation”.  
  Dessiner une courbe qui monte progressivement de **120 Hz (mesure 9)** à **220 Hz (mesure 24)**, puis redescend sur le refrain.
- **Volume** : *mf* → *f* sur le refrain, retour *mf* au couplet 2.

| Effet | Réglage |
|---|---|
| **MEqualizer** | Coupe-bas à 40 Hz (pente douce), léger boost à 100 Hz |
| **MSaturator** | Saturation douce (drive 20%), pour la chaleur |

## 2. PISTE NAPPES (Accordéon / Harmonium — Surge XT)

### Preset de départ
Chercher **Pads → “Warm Pad”** ou **“Church Organ”** dans les presets Surge XT[reference:3].

### Réglages Surge XT
| Paramètre | Valeur |
|---|---|
| Osc 1 | Wavetable “Organ” ou “Reed” |
| Osc 2 | Sinus, +7 demi-tons (quinte), volume 0.4 |
| Osc 3 | Bruit blanc très bas volume (0.05) |
| Filtre | Lowpass 12 dB, cutoff 800 Hz, résonance 0.2 |
| Enveloppe Amp | A: 400 ms, D: 600 ms, S: 0.8, R: 800 ms |

## GESTION RESSOURCES LIVE LITE

- **Freeze + Flatten** les pistes finies (Textures, Chœurs) → libère CPU
- **Regrouper** les Surge XT identiques dans un même Rack → économie d’instances
- **Éviter MConvolutionEZ multiple** → un seul dans le Return
- **Réduire la polyphonie** Surge XT à 8 voix par chaîne
- **Désactiver** les chaînes non utilisées via le bouton On/Off du Rack
- **Sauvegarder** chaque Rack comme preset utilisateur (.adg) pour réutilisation
