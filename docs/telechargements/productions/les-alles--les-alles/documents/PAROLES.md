# Les Allées — Paroles (Version Groovy/Funky)

**Tonalité :** Mi mineur (Em)
**Tempo :** 100 BPM
**Guide Voix :** Surge XT — Vocal Lead (track 3)
**Tessiture guide :** E3–B3 (baryton/ténor confortable)

**Structure :** Intro (4) → Couplet 1 (8) → Refrain 1 (8) → Couplet 2 (8) → Refrain 2 (8) → Pont + Solo (8) → Couplet 3 (8) → Refrain final (8) → **Ext. Refrain (8)** → **Outro Dub (8)** = **72 mesures**

**Accords :** Em7 | Am7 | Bm7 | Am7 (cycle de 4 mesures)

---

## Légende des annotations

- `E3 ◷3` = note E3 tenue 3 temps — attaquer la syllabe suivante sur cette note
- `→` = enchaînement sans nouvelle attaque
- `...` = silence / respiration
- `*(parlé)*` = effet de voix parlée / scat

## Notes d'arrangement

### Fills de batterie
- **Bar 36** : Tom fill (1 bar) → transition Refrain 2 → Pont + Solo
- **Bar 52** : Tom fill → transition Couplet 3 → Ext. Refrain

### Break (bars 35-36)
- Silence drums/keys/guide — basse seule tient E3
- Prépare l'entrée du solo au pont

### Analog Warmth (Master)
- **Limiter** : Soft Clip, Lookahead 6ms, Input Gain +0.65
- **Saturator** : Analog Clip, Drive 0.35, Dry/Wet 0.6 (parallèle)

## Notes d'adaptation

- Les notes marquent les **temps forts / syllabes accentuées** de chaque phrase
- Tu n'as pas à caler chaque syllabe exactement — suis la mélodie générale
- Le style est parlé-chanté, entre Gainsbourg et R&B nonchalant
- Le pont peut être allongé ou raccourci selon le feel
- Les ad-libs et effets *(parlé)* sont des indications d'arrangement vocal
