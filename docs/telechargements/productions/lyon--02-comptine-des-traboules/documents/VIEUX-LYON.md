# Vieux-Lyon — Comptine des Traboules

## Informations Générales

- **Disque** : Δίσκος 1 — Apollon Lyonnais
- **Quartier** : Vieux-Lyon (5e arr.)
- **Style** : Renaissance / Folk acoustique
- **BPM** : 88
- **Tonalité** : Ré mineur
- **Durée** : ~4min30
- **Voix** : Baryton — douce, comme une comptine murmurée

## Thème

Les traboules, ces passages secrets qui traversent les immeubles. Un enfant court, une mère appelle. Les pavés racontent des siècles d'histoire. Lyon garde ses mystères.

## Structure

```
Intro (8b) → Couplet A (16b) → Refrain (12b) → Pont (8b) → Couplet B (16b) → Refrain (12b) → Outro (16b)
Total : 88 mesures ≈ 4min
```

## Paroles Complètes

### [Intro] (8 mesures)
*(Psaltériel seul, pas dans une traboule en fond)*

### [Couplet A] (16 mesures)
Sous les arches du temps, où les secrets s'envolent
Les pavés racontent ce que les murs dissimulent
Une ombre glisse, un pas se perd dans les cours
Les traboules sont des veines, des chemins de secours

Un artisan tisse la soie dans la pénombre
Sa femme chante une mélodie d'autrefois
Les fenêtres s'ouvrent sur des cours intérieures
Où le temps s'est arrêté depuis des siècles

### [Refrain] (12 mesures)
Traboules, labyrinthes de pierre
Ombres qui dansent au crépuscule
Murmures d'un autre siècle
Lyon garde ses mystères

### [Pont] (8 mesures)
*(Parlé, comme un récit)*
Un enfant court, une mère appelle
Le soleil filtre entre les tuiles
Le passé vit dans chaque interstice
Vieux-Lyon, mémoire sans artifice

### [Couplet B] (16 mesures)
Les gargouilles sourient aux amoureux
Les artisans tissent encore leur soie
La Saône reflète les toits heureux
Et le temps s'arrête parfois

Un vieux monsieur assis sur son perron
Regarde les touristes défiler
Il se souvient quand les rues étaient siennes
Quand Lyon était sa ville

### [Refrain] (12 mesures)
Traboules, labyrinthes de pierre
Ombres qui dansent au crépuscule
Murmures d'un autre siècle
Lyon garde ses mystères

### [Outro] (16 mesures)
*(Comptine parlée, ralentissant)*
Une, deux, trois traboules,
Le chat s'enfuit, la lune est douce...
Quatre, cinq, six pas de lumière,
Les ombres dansent derrière...
Sept, huit, neuf silences,
Lyon rêve en silence...
