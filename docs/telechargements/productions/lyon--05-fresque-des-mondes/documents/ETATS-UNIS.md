# États-Unis (8e) — Fresque des Mondes

## Informations Générales

- **Disque** : Δίσκος 1 — Apollon Lyonnais
- **Quartier** : Quartier des États-Unis (8e arr.)
- **Style** : Electro-acoustique / Musique concrète / Spoken word
- **BPM** : Libre (tempo fluide)
- **Tonalité** : Atonale, centres sur Do mineur et Sol mineur
- **Durée** : ~5min
- **Voix** : Baryton — parlé-chanté, intense, proche du micro

## Thème

La mémoire des migrants, les fresques murales qui racontent des exils, des espoirs, des enfants qui jouent entre les tours. Chaque immeuble est un livre, chaque balcon un ailleurs.

## Structure

```
Prologue (field recordings) → Thème A (16b) → Interlude bruitiste (8b) → Thème B (16b) → Pont orchestral (12b) → Thème A' (16b) → Outro (12b)
Total : ~80 mesures (variables) ≈ 5min
```

## Accords (clusters, quartes, quintes)

```
Prologue : drones sur C – G – D (bourdon)
Thème A  : Cm(add9) – G7sus4 – Fmaj7#11 – Bb6/9
Interlude: clusters D – Eb – F# – G (résonances)
Thème B  : Dm9 – Bbmaj7#11 – Em7b5 – A7b13
Pont     : Fmaj9 – G13sus4 – Cm11 – Eb13#11 – Abmaj7#5
Thème A' : Cm(add9) – G7sus4 – Fmaj7#11 – Bb6/9 (plus dissonant)
Outro    : nappe de cordes qui s'éteint sur un C tenu
```

## Paroles Complètes

### [Prologue]
*(Bruits d'enfants, de langues étrangères, de casseroles)*
...Ici, les murs parlent...

### [Thème A] (16 mesures)
Ici, les langues s'entrechoquent
Comme les fresques sur les murs
Chaque immeuble raconte un exil
Chaque balcon porte un ailleurs

Les enfants inventent des alphabets
Avec des sons que les écoles n'apprennent pas
Ils dessinent des drapeaux Imaginaires
Sur les murs de béton qui les font rêver

### [Interlude bruitiste] (8 mesures)
*(Cris, klaxons, prières, percussions aléatoires)*

### [Thème B] (16 mesures)
Fatima a posé son tag
Juste à côté du drapeau algérien
Mamadou répare les mobylettes
Pendant que les pneus brûlent

Mais la vie est plus forte que les murs
Les fresques sont des fenêtres ouvertes
Sur des mondes qu'on n' imagine pas
Dans le bruit de la ville qui s'éveille

### [Pont orchestral] (12 mesures)
*(Cordes en crescendo, cuivres lointains)*

### [Thème A'] (16 mesures)
Les langues s'entrechoquent
Mais les enfants dansent
Ils inventent des rythmes
Que les adultes ont oublié

Demain, un autre visage
Une autre histoire à raconter
Les fresques changent de peau
Mais les murs se souviennent

### [Outro] (12 mesures)
...Et le soleil se couche sur les fresques...
...Demain, un autre visage, une autre histoire...
