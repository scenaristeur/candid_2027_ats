# Pentes (1er arr.) — Les Pentes Silencieuses

## Informations Générales

- **Disque** : Δίσκος 1 — Apollon Lyonnais
- **Quartier** : Les Pentes de la Croix-Rousse (1er arr.)
- **Style** : Rock atmosphérique / Post-rock / Ballade électrique
- **BPM** : 95
- **Tonalité** : Do# mineur
- **Durée** : ~5min
- **Voix** : Baryton — grave, rocailleux, presque murmuré

## Thème

Les nuits où les pentes descendent vers la ville, les graffs qui parlent, les amours clandestins, les révoltes endormies. L'énergie underground du quartier.

## Structure

```
Intro (8b) → Couplet A (12b) → Refrain (8b) → Interlude électrique (4b) → Couplet B (12b) → Refrain (8b) → Pont (8b) → Solo guitare (8b) → Outro (12b)
Total : 80 mesures ≈ 4min20
```
