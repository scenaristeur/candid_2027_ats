# Confluence — Cathédrale de Verre

## Informations Générales

- **Disque** : Δίσκος 1 — Apollon Lyonnais
- **Quartier** : Confluence (2e arr.)
- **Style** : Ambient progressif / Post-minimaliste / Soundscape
- **BPM** : 66
- **Tonalité** : Si mineur ↔ Ré majeur
- **Durée** : ~5min30
- **Voix** : Baryton — voix aérienne, en reverb immense, presque choir

## Thème

L'avenir qui se construit, la lumière qui traverse le verre, l'eau qui coule. Le Musée des Confluences comme cathédrale du futur. Les ouvriers qui posent des étoiles.

## Structure

```
Intro (16b) → Couplet A (16b) → Refrain (12b) → Interlude lumineux (8b) → Couplet B (16b) → Refrain (12b) → Pont (12b) → Outro (16b)
Total : 108 mesures ≈ 6min30
```
