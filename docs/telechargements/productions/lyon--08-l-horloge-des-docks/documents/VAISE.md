# Vaise — L'Horloge des Docks

## Informations Générales

- **Disque** : Δίσκος 1 — Apollon Lyonnais
- **Quartier** : Vaise (9e arr.)
- **Style** : Post-rock industriel / Cinématique
- **BPM** : 80
- **Tonalité** : Ré mineur ↔ Fa majeur
- **Durée** : ~5min
- **Voix** : Baryton — grave, usé, presque parlé

## Thème

Le temps qui passe sur les docks, les ouvriers qui ont vieilli, les grues qui ne tournent plus. La mémoire industrielle face au renouveau. Un vieux monsieur qui regarde le fleuve.

## Structure

```
Intro (8b) → Couplet A (16b) → Refrain (8b) → Interlude mécanique (8b) → Couplet B (16b) → Refrain (8b) → Pont (12b) → Outro (16b)
Total : 100 mesures ≈ 5min10
```
