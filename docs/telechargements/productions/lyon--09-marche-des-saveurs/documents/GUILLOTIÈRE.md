# Guillotière — Marché des Saveurs

## Informations Générales

- **Disque** : Δίσκος 2 — Dionysos au Confluent
- **Quartier** : Guillotière (3e/7e arr.)
- **Style** : Afro-house fusion / Électro-oriental
- **BPM** : 118
- **Tonalité** : Fa# mineur (mode Hijaz)
- **Durée** : ~5min
- **Voix** : Baryton — énergique, entraînant, multiculturel

## Thème

Le marché, les épices, les langues qui se croisent. Le muezzin chante, l'église répond. La Guillotière danse comme un samba sans frontière.

## Structure

```
Intro (16b) → Drop (8b) → Couplet A (16b) → Pont (8b) → Refrain (16b) → Break (8b) → Outro (12b)
Total : 92 mesures ≈ 4min
```

## Accords

```
Couplet A: F#m – E – F#m – C#7 (x2)
Pont     : D – E – F#m (mode Phrygien)
```
