# Duchère — Duchère Pulse

## Informations Générales

- **Disque** : Δίσκος 2 — Dionysos au Confluent
- **Quartier** : Duchère (9e arr.)
- **Style** : Rap conscient / Neo-soul / Urban
- **BPM** : 100
- **Tonalité** : Fa mineur ↔ Sol# majeur
- **Durée** : ~4min30
- **Voix** : Baryton — flow posé, grave, incisif sur les refrains

## Thème

La vie dans les hauteurs, les espoirs des jeunes, les tours qui regardent la ville, la musique qui monte de la cité. Résilience et amour.

## Structure

```
Intro (8b) → Couplet A (16b) → Refrain (12b) → Interlude (4b) → Couplet B (16b) → Refrain (12b) → Pont (8b) → Outro (12b)
Total : 100 mesures ≈ 5min
```
