# Pentes (remix) — Graffiti Sonore

## Informations Générales

- **Disque** : Δίσκος 2 — Dionysos au Confluent
- **Quartier** : Les Pentes de la Croix-Rousse (1er arr.)
- **Style** : Techno acide / Electro (remix du Disque 1)
- **BPM** : 132
- **Tonalité** : La mineur
- **Durée** : ~5min
- **Voix** : Baryton — moins grave, plus robotique (vocodeur)

## Thème

La même chanson que le Disque 1 (*Les Pentes Silencieuses*), mais en version techno/rave. Pour danser sur les pentes.

## Structure

```
Intro (16b) → Couplet A (16b) → Refrain (16b) → Break (8b) → Drop (32b) → Couplet B (16b) → Refrain (16b) → Outro (16b)
Total : 136 mesures ≈ 4min10
```

## Accords

Identiques au Disque 1, mais avec des synthés acides (résonance, sweep).

## Paroles

Identiques au Disque 1, mais processing vocal : vocodeur + distorsion sur les refrains.

### Extraits clés
Pentes silencieuses, vous avez vu
Des révolutions, des amours déçues
Vos pavés gardent les promesses
Que les nuits effacent sans cesse
