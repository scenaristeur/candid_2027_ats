# Confluence — Confluence Extasy

## Informations Générales

- **Disque** : Δίσκος 2 — Dionysos au Confluent
- **Quartier** : Confluence (2e arr.)
- **Style** : Deep house / Techno minimale (remix du Disque 1)
- **BPM** : 124
- **Tonalité** : Ré mineur
- **Durée** : ~5min
- **Voix** : Baryton — plus rythmée, presque parlée

## Thème

La même que le Disque 1 (*Cathédrale de Verre*), mais en deep house pour les clubs. L'eau coule, le beat pulse.

## Structure

```
Intro (16b) → Couplet A (16b) → Refrain (16b) → Drop (32b) → Couplet B (16b) → Refrain (16b) → Outro (16b)
Total : 128 mesures ≈ 5min10
```

## Accords

Identiques au Disque 1, avec extensions de 9e, 11e, 13e.

## Paroles

Identiques au Disque 1.
