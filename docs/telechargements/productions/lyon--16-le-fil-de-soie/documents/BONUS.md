# Le Fil de Soie (Bonus — Inter-disques)

## Informations Générales

- **Disque** : Bonus (les deux disques)
- **Style** : Duo kora/bouzouki → version acoustique (Apollon) + remix électro (Dionysos)
- **BPM** : Variable
- **Tonalité** : Mi mineur
- **Durée** : ~3min30 (version acoustique) + ~4min (remix)
- **Voix** : Baryton — doux, poétique

## Thème

Un fil de soie entre deux collines. Le Rhône et la Saône enlacent la ville. Lyon tisse le temps, le temps le délace. Pont entre les deux albums.

## Structure

```
A (8b) – B (8b) – A' (8b) – C (16b) – Solo (12b) – Coda (8b)
Total : 60 mesures
```

## Accords

```
Version acoustique : Em – C – G – D (open tuning)
Version électro : Em(add9) – Cmaj7 – Gsus2 – D/F# (avec bass 808)
```

## VERSION 1 : Apollon (Acoustique)

### Piste 1 — Voix (Audio)

**Traitement :**
- Voix chuchotée (couplet A), chantée (B, C)
- Reverb Hall : 30%
- Delay 1/4 : 10%

### Piste 2 — Kora (Surge XT — Harpe)

**Patch :**
- Osc 1 : Sine + FM 20%, Level -8dB
- Filter : LP 12dB, Cutoff 3kHz
- Env : Attack 0.01s, Decay 1s, Sustain 30%, Release 2s

### Piste 3 — Contrebasse (Surge XT — Bass)

**Patch :**
- Osc 1 : Square, Octave 2, Level -12dB
- Filter : LP 24dB, Cutoff 300Hz

### Piste 4 — Cordes (Surge XT — Strings)

**Patch :**
- Osc 1 : Saw, Level -12dB
- Filter : LP 12dB, Cutoff 600Hz
- Env : Attack 1s, Release 3s

### Piste 5 — Percussions légères (Drum Rack)

**Cellules :** Triangle, tambourin (très espacés)

### Piste 6 — Samples (Eau — Audio)

**Field recordings de la Saône**

### Piste 7 — Nappes (Surge XT — Pad)

**Patch :** Sine, Level -16dB, Reverb 40%

### Piste 8 — Retour FX (Audio)

- Reverb Hall + Delay

## VERSION 2 : Dionysos (Électro)

### Piste 1 — Voix (Audio)

**Traitement :**
- Vocoder (carrier = synthé saw)
- Distorsion légère
- Delay ping-pong : 20%

### Piste 2 — Reese bass (Surge XT — Bass)

**Patch :**
- Osc 1 : Saw + Saw (désaccordé), Level -6dB
- Filter : LP 24dB, Cutoff 200Hz
- Env : Attack 0.01s, Decay 0.5s, Sustain 80%, Release 0.2s
- FX : Distortion

### Piste 3 — Pluck FM (Surge XT — Pluck)

**Patch :**
- Osc 1 : Sine + FM 25%, Level -8dB
- Env : Attack 0.01s, Decay 0.3s, Sustain 30%, Release 0.2s

### Piste 4 — Drum Rack (Beat)

**Cellules :**
- Kick 808 (lourd)
- Clap
- Hi-hats (swing 55%)

### Piste 5 — Samples (Métier à tisser — Audio)

**Field recordings granulés de métiers à tisser**

### Piste 6 — Synth lead (Surge XT — Lead)

**Patch :**
- Osc 1 : Saw, Level -8dB
- Filter : LP 12dB, Cutoff 2kHz

### Piste 7 — Nappes (Surge XT — Pad)

**Patch :**
- Osc 1 : Saw, Level -14dB
- Filter : LP 24dB, Cutoff 600Hz
- FX : Reverb, Delay

### Piste 8 — Retour FX (Audio)

- Reverb + Delay

## Workflow Ableton

1. Créer un template avec 2 groupes : "Apollon" / "Dionysos"
2. Utiliser "Instrument Rack" pour basculer entre versions
3. Automatiser un macro :
   - Knob 1 : Acoustic → Electric
   - Knob 2 : Reverb Size
   - Knob 3 : Sample Rate Reduction
   - Knob 4 : LFO Rate (lié à Pan)
