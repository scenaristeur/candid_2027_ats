# 04 — Solitude
*(anciennement « Interlude : V.C.V. Solitude » — tout en Ableton Live Lite)*

**Tempo**: Temps libre (free time, sans pulsation stricte)
**Tonalité**: Noyau sur F#, évolution
**Durée**: ≈ 3 min
**Atmosphère**: Isolément, vide, dissolution
**Style**: Interlude instrumentale, pont émotionnel
**Voix**: Aucune (instrumental)

## Hommage
- Pink Floyd : nappes amples, recueillement
- Ambiances sonores : évolution lente, silence habité

## Structure (phases de tension, pas de barres strictes)
Phase 1 : Noyau (F#m11) → Phase 2 : Déchirure (F#m11 + G4) → Phase 3 : Dissolution (Bbmaj7#11)

## Grille / tensions

| Phase | Accord / Tension | Geste live |
| :--- | :--- | :--- |
| **1. Noyau** | Un seul accord étiré : `F#m11(no3)` | Varier cutoff filtre + feedback delay avec de lents LFOs. La simplicité crée l'espace. |
| **2. Déchirure** | Superposition `F#m11` + `G4` (note de friction) | Introduire manuellement la friction. La dissonance = « l'écharde dans la mémoire ». |
| **3. Dissolution** | Évolution vers `Bbmaj7#11` | Estomper la friction, laisser la fondamentale descendre lentement vers Sib. La #11 apporte une lumière froide. |

## Instruments (Ableton) — Mix

| Piste | Instrument | Pan | Vol | Chaîne FX |
| :--- | :--- | :--- | :--- | :--- |
| **Nappes** | Analog Lab — `Atmo Pad` | — | — | Simple, étiré |
| **Effets** | — | — | — | `Auto-Filter`, `Echo`, `Reverb Max` (automation du cutoff et du feedback) |

**Basse** : sur note pédale (ex : F#) avec automation de filtre.

## Automations

| Moment | Automation | Effet produit |
| :--- | :--- | :--- |
| **Phase 2** | Cutoff filtre se ferme | Étranglement, tension. |
| **Phase 3** | Feedback delay diminue | Les grains se dissolvent dans le silence. |

## Notes de production

- La mélodie *est* le mouvement du son : oscillateurs lents modulant d'autres paramètres.
- **Impro** : toute la pièce est improvisée — manipulation live des filtres et du delay.

## Notes live (set)

- Transition entre « Fantom Lover » (funk) et « Lost in Supermarket » (groove sombre).
- Visuel : projection d'une onde/forme qui se dissout.
