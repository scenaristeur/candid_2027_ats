**Structure :** Phase 1 : Noyau (F#m11) → Phase 2 : Déchirure (F#m11 + G4) → Phase 3 : Dissolution (Bbmaj7#11)

## Légende

- Pièce **instrumentale** sans chant.

---

## Phase 1 : Noyau

*F#m11 étiré. Cutoff du filtre et feedback du delay varient lentement. Le vide crée l'espace.*

---

## Phase 2 : Déchirure

*Friction G4 introduite. La dissonance = « l'écharde dans la mémoire ». Le filtre se ferme, étranglement.*

---

## Phase 3 : Dissolution

*La friction s'estompe, la fondamentale descend lentement vers Sib (Bbmaj7#11). Les grains se dissolvent dans le silence.*

**Aucune parole. Le silence parle.**
