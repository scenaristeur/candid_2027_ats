**Tempo**: Variable
**Tonalité**: Libre (boucle Am7 - D9)
**Durée**: ≈ 5-8 min
**Atmosphère**: Improvisation totale, interaction publique
**Style**: Plage d'impro live
**Voix**: Aucune écrite — l'instant décide

## Notes d'improvisation

- **Ancrage** : garder un élément constant (un drone, un motif de kick simple) pour cadrer l'impro.
- **Interaction** : inviter un spectateur à tourner les knobs du contrôleur MIDI.
- La boucle **Am7 - D9** offre un terrain harmonique stable pour l'exploration solo.
