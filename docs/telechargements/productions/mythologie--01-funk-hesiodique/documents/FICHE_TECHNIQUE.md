### Convention de longueur (fixée après calcul syllabique)
- **Clips backing** (drums/basse/lead/rhodes/brass) = **16 beats (4 barres)** = un motif qui se répète.
- **Clips guide vocal** = **32 beats (8 barres)** = couvrent les 2 tours du backing, avec TOUTES les paroles de la section.
- **Intro** = **48 beats (12 barres)** (3 phrases qui respirent : débit parlé ~2 syll/s, ligne 2 = 23 syll ≈ 4 barres).
- À l'assemblage arrangement : placer chaque backing ×2 + guide ×1, en respectant l'ORDRE de la chanson (voir plus bas).

### ⚠️ PLACE DES CLIPS EN SESSION (ordre logique chanson vs slots)
- **Slot 0 = Intro (48 beats)** · **Slot 1 = Couplet 1** · **Slot 2 = Refrain** · **Slot 3 = Couplet 2** · **Slot 4 = Couplet 3** · **Slot 5 = Pont** · **Slot 6 = Refrain final** · **Slot 7 = Outro**
- ⚠️ Ordre d'exécution vrai dans la chanson : Intro → Couplet 1 → Couplet 2 → **Refrain (slot 2)** → Couplet 3 → Pont → Refrain final → Outro. Le slot 2 contient déjà le Refrain, PAS besoin de le dupliquer (réutilisable).
- **ORDRE D'ASSEMBLAGE (arrangement, PAS maintenant) :** Intro (0) → Couplet1 (1) → Couplet2 (3) → Refrain (2) → Couplet3 (4) → Pont (5) → RefrainFinal (6) → Outro (7). Chaque section = backing ×2 tours + guide ×1 de 32 beats.
- L'assemblage final se fera à l'étape arrangement (PAS maintenant).

## Groove / Drums (Drum Rack 909)

- **Kick** : syncopé — joue 1, puis contretemps 2e division (1.2+)
- **Snare** : sur 2 et 4, bien carrée (PAS de swing dessus)
- **Closed Hat** : 16èmes continus, accents sur contretemps, vélocités variées (60-110), humanisation
- **Open Hat** : ponctuel (sur le contretemps de la mesure 2), vélocité ~95
- **Clap** : sur les \& de la snare (1.4+)
- **Fill** : roulement de snare en doubles-croches (1.3.3 → 1.4.2) sur la 4e mesure
- **Shaker** : 16èmes continus dans les refrains, disparaît dernier temps

### Pattern type (2 barres, couplet)
```
Barre 1 : Kick [1, 1.2+] · Snare [4] · Clap [4+] · CHH 16e
Barre 2 : Kick [1] · Snare [4] · Clap [4+] · OHH [2.2+] · Ghost kick [3+]
```
Variation barre 4 : snare roll → clap → open hat.
