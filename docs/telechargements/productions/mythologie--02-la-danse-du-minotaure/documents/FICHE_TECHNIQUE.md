# Fiche Technique — 02 · La Danse du Minotaure

Album **FunkAntik** · Chanson 2 · Concept : le labyrinthe de Crète.
Le groove cyclique hypnotique = le labyrinthe. Le funk dark qui tourne, le Minotaure qui danse dans le rond.

---

## Paramètres globaux

| Paramètre | Valeur |
|---|---|
| BPM | **96** (lent, hypnotique — plus lourd que le 108 d'Hésiode) |
| Signature | 4/4 |
| Tonalité | **Do mineur (C minor)** — plus sombre qu'Hésiode (E minor) |
| Groove | Cyclique, saturation bass, anti-chorus (jamais de "big climax", toujours le même motif) |
| Concept | La 1re chanson (Hésiode) était la colère du sol ; celle-ci est la peur du rond |
| Style | **Funk dark hypnotique** — 4/n-♪ groove répétitif, tension constante |

## Grille harmonique (Do mineur, virevoltante)

### Couplets — le labyrinthe (2 mesures de tension, 2 de résolution partielle)
| Mesure | Accord | Note |
|---|---|---|
| 1 | **Cm9** | C-Eb-G-Bb-D |
| 2 | **Cm9** (persiste) | hypnotique |
| 3 | **Ab maj7** | une "fenêtre" dans le mur |
| 4 | **Bb7** | la tension qui tourne |

### Refrain — le Minotaure (tourne sans se résoudre)
| Mesure | Accord | Note |
|---|---|---|
| 1 | **Cm9** | toujours |
| 2 | **Fm9** | le "monstrueux" |
| 3 | **Ab maj7** | |
| 4 | **G7(#5)** | la dissonance du rond |

### Pont — l'issue
Cm9 (2ms) → Ab maj7 (2ms) → Fm9 (2ms) → **Bb7 → Cm9** (retour au fil)

## Effets / Automations clés

- **Sidechain** kick → basse + lyre (pompage obstiné, le "cœur du monstre")
- **Congas/cowbell** : le rituel approchant (comme appris dans Hésiode)
- **Filter sweep lent** sur la flûte : le couloir qui se resserre
- **Auto-Pan / tremolo** sur les cordes : l'oscillation du dédale
- **Master** : compressor glue + limiter, très fidèle à Hésiode (glue + vrai peak)

## Ear candies

1. **Le faux ending** avant le refrain final : tout s'arrête 1/2 temps, puis le rond reprend
2. **La basse qui "tourne"** : micro-variation d'une note par couloir (très subtil)
3. **Cordes en pizz** au pont : la corde d'Ariane qui vibre
4. **Fin** : les congas s'éloignent (auto-pan + baisse), la corde reste au sol, silence brutal
5. **Whisper intro** : "tourne, tourne, tourne" en grain
