# 02 — Marteau-Pilon

**Tempo**: 122 BPM
**Tonalité**: Mi mineur (Em) blues
**Durée**: ≈ 3 min (96 barres — arrangement complet)
**Atmosphère**: Forge, hard rock blues, violence contenue
**Style**: Hommage Led Zeppelin + Deep Purple
**Voix**: Baryton puissant en poitrine (Mi3 → Sol3), overdrive vocal 30% sur le refrain (« forgé »)

## Hommage
- Led Zeppelin : riff massif, double tracking guitare, basse qui groove
- Deep Purple : orgue B3 rotatif, duel solo guitare/orgue, énergie Hammond
- Contemporain (2026) : saturation « Saturn » sur la basse, production qui claque sans ringardise

## Structure (en barres)
Riff (8) | Couplet 1 (16) | Refrain 1 (8) | Couplet 2 (16) | Refrain 2 (8) | Pont (8) | Duel solo Guitare/Orgue (16) | Refrain 3 (8) | Outro (8) = **96 barres**

## Production Notes

- Double tracking guitare : deux prises (ou deux pistes) légèrement décalées pour le « mur » Zep.
- Kick sur 1, snare sur 3 : backbeat simple qui laisse la place au riff.
- Le pont est le point de respiration avant le duel : baisser la batterie, laisser l'orgue respirer.

## Notes live (set)

- Arrive en transition sans blanc depuis « Le Bruit des Vagues » (drone d'orgue).
- Le duel guitare/orgue est le moment spectacle : les deux musiciens face à face.
- Visuel rouge/forge, flammes sur le refrain.
