# 01 - One-Drop Base (validation étape 1)

**Validé à l'oreille par David** — groove + matière du kit retenus pour démarrer.

## Paramètres
- Tempo : **100 BPM**
- Tonalité : **Do#m (C#m)**
- Style : reggae rub-a-dub façon Massilia Sound System (ragga occitan)

## Piste 1 — Batterie
- Kit : `Selector Kit Warm.adg` (query:Drums#FileId_5282) — chaud, organique
- Clip : « One-Drop Base », 2 barres (8 temps)
- Pads : Kick=36, Snare=38, Hihat Closed=42, Shaker=44

## Groove
- **One-drop** : grosse caisse (36) + caisse claire (38) ensemble sur le **3e temps** (index 2 et 6). Pas de kick sur le 1er temps = balancement « en arrière ».
- Charleys fermés (42) en croches continues, léger accent sur les temps forts.
- 20 notes, clip 2 barres.

## Prochaine étape
Basse sur le 1er temps en Do#m — donne le poids. À valider à l'oreille.
