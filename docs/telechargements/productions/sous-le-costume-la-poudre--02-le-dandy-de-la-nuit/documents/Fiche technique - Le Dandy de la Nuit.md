# Fiche Technique — 02 — Le Dandy de la Nuit

**Album** : SOUS LE COSTUME, LA POUDRE
**Type** : Salsa Dura
**Tempo** : ~92 BPM (2/2 ou 4/4, clave)
**Tonalité** : La mineur (Am) avec tonique ambiguë (Mi7)
**Durée** : ~3'10

## Concept

Présentation du personnage. Victor Delacroix entre dans la salle, les regards se
figent. Rythme nerveux, cuivres agressifs. C'est le « titre — carte de visite » :
on pose le héros, son goût (trois-pièces gris, rhum sans glace), son arme
(un calibre) et sa douleur (ses yeux).

## Structure (en mesures, indicative)

| Section | Mesures | Description |
|---|---|---|
| Intro | 4 | Riff cuivres + clave, entrée sèche |
| Couplet 1 | 8 | Piano montuno, trompette en écho |
| Refrain | 8 | Cuivres pleins, chœurs |
| Couplet 2 | 8 | Gauche/pawns stride, basse en marche |
| Refrain | 8 | Pic d'énergie |
| Pont | 4 | Break percussions, tension |
| Montuno final | 8 | Soli cuivres, montée en furie |
| Outro | 4 | Couper net, enchaîne sur titre 3 |

## Automations / Ambiance

- Cuivres : montée en `f` sur le refrain, `mf` au couplet.
- Reverb camion : très sèche, sauf sur les breaks.
- Le break du pont est « nu » (percussions seules) avant le retour en montuno.
