# Fiche Technique — 03 — La Banque des Sans-Cœur

**Album** : SOUS LE COSTUME, LA POUDRE
**Type** : Guaguancó (rythmique syncopée, percussions tribales)
**Tempo** : ~90 BPM
**Tonalité** : Sol mineur (Gm)
**Durée** : ~3'00

## Concept

Le casse. Victor pirate les coffres d'une banque d'affaires qui expulse des familles.
Rythme syncopé, percussions tribales, guaguancó qui donne le groove. Le vol est une
**fête** — on bénit le butin et on le reverse aux gosses.

## Ambiance / Effets

- Salle de coffre : ondes de basse, bruit de métal (codé, digital).
- Le « compte à rebours » au couplet 1 (bips / tick digital) sous les congas.
- Bruit du « clic » du code bancaire qui s'ouvre → reverse sample (caisse).
