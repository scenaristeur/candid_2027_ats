# 03 — La Banque des Sans-Cœur — Paroles

**Style :** Guaguancó (rythmique syncopée, percussions tribales)
**Tempo :** ~90 BPM
**Tonalité :** Sol mineur (Gm)
**Voix :** Baryton/tenor
**Durée :** ≈ 3'00

**Structure :** Intro → Couplet 1 → Refrain → Couplet 2 → Refrain → Montuno → Outro

---

## Légende

- **Gras** = mots à appuyer.
- *Italique* = soufflé / digital.

---

## Intro (4 mesures)

*Clave + congas. Bips discrets d'un clavier, on tape un code dans l'ombre.*

---

## Couplet 1

Minuit sonne, les gardes **dansent au bal**,
Victor ouvre le code avec un logiciel fatal.
Il glisse dans le réseau comme une ombre mouillée,
*Le terminal cligne : trois secondes, verrouillé.*

*(le compte à rebours vire sous les percussions)*

---

## Refrain

**Il croque le bifton, les actions, les lingots,**
**Et laisse un mot doux : "Pour les gosses de Sarcelles".**
**Que la salsa brûle, que le feu soit doux,**
**Ce soir, l'argent vole pour ceux qui sont à genoux !**

---

## Couplet 2

Les coffres s'alignent comme des veuves fidèles,
Il les ouvre d'un geste, une flûte à la main cruelle.
Les distributeurs crachent, les comptes se déchirent,
*Dans la banque des sans-cœur, il met le feu d'en dessous.*

*(break : coup de tambour, le lingot sort de l'étui doré)*

---

## Refrain

**Il croque le bifton, les actions, les lingots,**
**Et laisse un mot doux : "Pour les gosses de Sarcelles".**
**Que la salsa brûle, que le feu soit doux,**
**Ce soir, l'argent vole pour ceux qui sont à genoux !**

---

## Montuno (solo percussions + cuivres)

*(poussez les congas en guaguancó, campana qui s'emballe)*
¡Guaguancó, guaguancó!
*Pour les mioches… pour les mères… pour Sarcelles !*
**¡Que arda, que suene !**

*(le solo de cuivres répond à chaque figure de conga)*

---

## Outro

*(soufflé, la clave ralentit)*
…Et laisse un mot doux,
*Pour les gosses de Sarcelles.*

*(fade sur les congas qui martèlent — enchaîne sans blanc sur « Le Bal des Millionnaires »)*

---

## Notes d'interprétation

- Couplet : **froideur de l'opération** (le casse est chirurgical), voix contenue.
- Refrain : **explosion joyeuse** — le vol est une fête, pas un crime.
- Montuno : la percussion est le narrateur, la voix cède la parole aux congas.
- Fin : chaleur — le butin rendu, le ton redevient doux.
