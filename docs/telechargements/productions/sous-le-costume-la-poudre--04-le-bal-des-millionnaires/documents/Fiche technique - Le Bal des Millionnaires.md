# Fiche Technique — 04 — Le Bal des Millionnaires

**Album** : SOUS LE COSTUME, LA POUDRE
**Type** : Bolero-Salsa (langoureux, violons)
**Tempo** : ~78 BPM (boléro) → accélère vers la salsa
**Tonalité** : Mi mineur (Em) / Mi majeur (E)
**Durée** : ~3'30

## Concept

Un duo sensuel. Victor séduit la femme d'un armateur corrompu pour obtenir un mot de
passe. Tension entre passion réelle et manipulation. Mélodie langoureuse, violons.
C'est le titre « séduction » — chaud, velours, ambiguïté morale.

## Structure (en mesures, indicative)

| Section | Mesures | Description |
|---|---|---|
| Intro | 4 | Violons nappe, piano boléro, un regard |
| Couplet 1 | 8 | Boléro lent, voix chaude |
| Refrain | 8 | Montée, la salsa s'emballe, cuivres |
| Couplet 2 | 8 | Les mains s'approchent, le mot de passe affleure |
| Refrain | 8 | Fièvre |
| Pont | 4 | Break, elle glisse le sachet—tension |
| Outro | 4 | Il l'embrasse, se lève, mot de passe en poche |

| 4 | Percussions | Clave 3-2/2-3, guiro, maracas |
| 5 | Voix (Victor) | Baryton, velours |

## Automations / Ambiance

- La voix d'« Elle » : légèrement plus faible / plus aiguë, une harmonie loin.
- Le mot de passe murmuré sur le pont (effet : voix chuchotée, un clin d'œil).
- Reverb salle de bal (grande salle), delay léger sur la trompette.

## État de production

🔶 **Fiche prête — maquette à créer.** Duo : il faut définir si « Elle » est chantée par une invitée ou doublée.
