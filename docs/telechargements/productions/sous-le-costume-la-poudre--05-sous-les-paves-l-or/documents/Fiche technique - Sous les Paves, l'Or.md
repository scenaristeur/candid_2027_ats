# Fiche Technique — 05 — Sous les Pavés, l'Or

**Album** : SOUS LE COSTUME, LA POUDRE
**Type** : Timba Cubaine (explosif, chœurs joyeux)
**Tempo** : ~102 BPM
**Tonalité** : Do majeur (C) — luminosité, fête
**Durée** : ~3'20

## Concept

L'explosion de joie. Victor reverse des millions en cryptomonnaies aux associations et
paie les loyers impayés. Rythme explosif, chœurs joyeux, timba moderne. C'est LE pic
festif de l'album : une fête de rue qui célèbre le don.

## Structure (en mesures, indicative)

| Section | Mesures | Description |
|---|---|---|
| Intro | 4 | Timba, cuivres qui explosent, campana |
| Couplet 1 | 8 | Les loyers payés, les frigos remplis |
| Refrain | 8 | « Vole, mon argent » — chœurs joyeux |
| Couplet 2 | 8 | Les mômes en baskets |
| Refrain | 8 | Pic |
| Montuno Timba | 8 | Solo piano/percussions, chœurs de rue |
| Outro | 4 | Fiesta qui se prolonge, fondu |

## Pistes envisagées

| # | Piste | Instrument / FX |
|---|---|---|
| 0 | Timba keys (piano) | Montuno percussif, « piano du tumbao » |
| 1 | Timbal | Roll, cowbell, crash |
| 2 | Bass | Tumbao, lucumi |
| 3 | Percussions | Congas, bongo, campana, maracas |
| 4 | Cuivres | Stabs joyeux, réponses |
| 5 | Guitare | (tres) son montuno |
| 6 | Chœurs | Joyeux, doublés, ceux de la rue |
| 7 | Voix | Baryton/tenor, rayonnant |

## Automations / Ambiance

- Ambiance de rue (fête, klaxons doux, applaudissements) en fond sur l'intro/outro.
- Crescendo de chœurs sur le refrain — tout le « quartier » chante.
- Vibration lumineuse : mix plutôt ouvert, reverb de place publique.

## État de production

🔶 **Fiche prête — maquette à créer.** Paroles : extraits approuvés, à développer.
