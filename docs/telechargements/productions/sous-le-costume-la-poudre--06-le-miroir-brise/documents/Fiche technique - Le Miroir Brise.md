# Fiche Technique — 06 — Le Miroir Brisé

**Album** : SOUS LE COSTUME, LA POUDRE
**Type** : Salsa Romántica (mélancolique, piano triste)
**Tempo** : ~70 BPM (sentimental) → contre-temps salsa légère
**Tonalité** : Ré mineur (Dm)
**Durée** : ~3'00

## Concept

Le doute. Son meilleur ami (un flic) est sur le point de l'arrêter. Victor regarde
son reflet dans une vitrine brisée. Piano triste, mélodie mélancolique : l'album
bascule — le justicier s'interroge sur son propre reflet.

## Structure

| Section | Mesures | Description |
|---|---|---|
| Intro | 4 | Piano triste, reflet dans la vitre |
| Couplet 1 | 8 | « Qui suis-je ? » — doute |
| Refrain | 8 | Le miroir brisé, la contradiction |
| Couplet 2 | 8 | L'ami flic approche |
| Refrain | 8 | Tension |
| Pont | 4 | Face à face avec le flic (les yeux) |
| Outro | 4 | Confiance maintenue, mais fissure |

## Pistes envisagées

| # | Piste | Instrument / FX |
|---|---|---|
| 0 | Piano | Ballade triste, pad |
| 1 | Violons / Boston | Nappe triste |
| 2 | Contrebasse | Marche douce |
| 3 | Percussions | Légères — guiro, maracas, pas de bomb-bomb |
| 4 | Cuivres | Rares, sourdines (voile) |
| 5 | Voix | Baryton, émotion à fleur de peau |

## Automations / Ambiance

- Bruit de verre brisé en intro (sample), réutilisé au pont.
- Le piano « pleure » (arpeggio) sous le refrain.
- Tout est plus sec, plus intime que les titres festifs — on s'approche du visage.

## État de production

🔶 **Fiche prête — maquette à créer.** Paroles : extraits approuvés, à développer.
