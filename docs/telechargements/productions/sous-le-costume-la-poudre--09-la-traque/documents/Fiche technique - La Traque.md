# Fiche Technique — 09 — La Traque

**Album** : SOUS LE COSTUME, LA POUDRE
**Type** : Salsa Dura (cavale, course-poursuite)
**Tempo** : ~105 BPM, nerveux, hypnotique
**Tonalité** : Mi mineur (Em), basse sautillante
**Durée** : ~3'10

## Concept

La cavale. Poursuite dans les docks entre les containers, alors que Victor est traqué
par la police et les tueurs du cartel envoyés par sa complice. La basse sautillante,
les sirènes déformées en trombones, les cuivres qui zigzaguent. L'adrénaline pure
d'un homme qui sème ses ennemis — le costume froissé mais le sourire intact.

## Structure

| Section | Mesures | Description |
|---|---|---|
| Intro | 4 | Basse sautillante, sirènes en stabs, course |
| Couplet 1 | 8 | Les containers, le zigzag |
| Refrain | 8 | L'échappée, sirènes-trombones |
| Couplet 2 | 8 | Les deux ennemis qui s'entrecroisent |
| Refrain | 8 | Pic d'adrénaline |
| Break | 4 | Roulement timbales, pause suspendue |
| Montuno final | 8 | Fureur, la fuite s'accélère |
| Outro | 4 | Saut, impact, il s'échappe — enchaîne |

## Pistes envisagées

| # | Piste | Instrument / FX |
|---|---|---|
| 0 | Basse | Sautillante, syncopée, lucumi rapide |
| 1 | Cuivres | Sirènes déformées (trombone), stabs |
| 2 | Percussions | Congas, bongo, campana rapide |
| 3 | Timbales | Roll, accents |
| 4 | Piano | Montuno nerveux |
| 5 | Voix | Baryton, haleté, vif |
| 6 | FX | Sirènes, containers (métal), klaxon |

## Automations / Ambiance

- Sirènes de police **déformées** en trombones (sounding comme des cuivres).
- Bruits de containers (impact métal) sur les coups forts.
- Le break est quasi silencieux — une seconde de calme avant la reprise en furie.

## État de production

🔶 **Fiche prête — maquette à créer.** Paroles : extraits approuvés, à développer.
