# Fiche Technique — 10 — El Corazón del Barrio

**Album** : SOUS LE COSTUME, LA POUDRE
**Type** : Descarga (jam instrumental, fête spontanée)
**Tempo** : ~100 BPM
**Tonalité** : Do majeur (C) festif
**Durée** : ~3'30 (jusqu'à 4')

## Concept

Morceau purement instrumental. Une descarga = jam session latine libre. Un long solo
de timbales, de trompettes et de piano montuno. Cela représente la fête spontanée du
quartier quand les gens apprennent qu'ils sont sauvés. Ambiance de rue, fiesta — MAIS
Victor n'est pas là : le peuple danse sans savoir le drame de la piste 8-9.

## Structure (jam)

| Section | Mesures | Description |
|---|---|---|
| Grossissement | 4-8 | Percussions entrent une à une |
| Montuno | 8-16 | Piano mene le groove |
| Solo Trompette | 16 | Cuivre en tête |
| Solo Timbales | 16 | Percussion soliste (rolls) |
| Solo Piano | 16 | Montuno virtuose |
| Tutti / Climax | 16 | Tout le monde joue, fête totale |

## Pistes envisagées

| # | Piste | Instrument / FX |
|---|---|---|
| 0 | Piano | Montuno solo |
| 1 | Cuivres | Stabs d'ensemble + soli |
| 2 | Timbales | Soli + accélérations |
| 3 | Percussions | Congas, bongo, campana, guiro |
| 4 | Basse | Tumbao |
| 5 | Ambiance rue | Voix de quartier, klaxons, applaudissements (en fond) |

## Automations / Ambiance

- Les soli passent le micro (attack/reverb sur le solo).
- La « rue » (bruit ambiant) reste en sourdine derrière le mix.
- Crescendo continu : la fête monte sans jamais redescendre jusqu'au climax.

## État de production

🔶 **Fiche prête — maquette à créer.** Instrumental pur (jam), pas de paroles.
