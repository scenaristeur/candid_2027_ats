# 13 — Édouard Philippe — Le Havre, la dette et les familles — Paroles

**Tonalité** : Do dièse mineur (C#m)
**Tempo** : 84 BPM
**Voix** : baryton parlé-chanté, E3–B3 (MIDI 64–71, convention Ableton C3 = 60)
**Durée** : ≈ 2 min 45
**Structure** : Intro piano (8) → Couplet 1 (16) → Refrain (8) → Couplet 2 (16) → Refrain (8) → Pont instrumental (8) → Refrain final (8) → Outro (8) = 80 barres

## Légende

- **Gras** = appui poitrine de baryton
- *Italique* = voix mixte, plus légère
- *Texte en italique entre parenthèses* = indication de jeu, pas à chanter
- Le morceau est **lent et peu rempli** : les silences font partie du texte.

## Notes d'interprétation

- **Registre** : c'est un morceau de **nuances**, pas de puissance. Si la voix force, le morceau perd son sujet.
- **Couplets** : presque une note de synthèse lue à voix haute. Les chiffres portent le sens ; ne pas les noyer dans la mélodie.
- **Refrain** : mélodie simple, presque enfantine, pour contraster avec les chiffres. C'est ce contraste qui critique.
- **Pont** : instrumental. Ne pas ajouter de texte : le silence est le seul endroit où le morceau respire.
- **Dernière ligne** : « attend toujours son tour » doit être dit, pas chanté. C'est la critique, et elle est douce.

## Sources et points à vérifier avant enregistrement

- **Correction importante** : le brief attribue à Édouard Philippe la réforme des retraites de 2023.
